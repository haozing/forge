**D-16（缺陷，已修）**：审核/删除评论未发失效事件（设计 §8.4 要求 site.site_changed，实施遗漏）——p9 主链"批准后可见"当时靠创建事件的延迟处理碰巧通过，机制上页面可陈旧至 TTL。修复：ModerateComment/DeleteComment 发 `site.site_changed(action=comment_moderated)`；G9 用"缓存已预热→仅审核动作→≤25s 页面更新"确定性回归。

**D-17（缺陷，已修，G8 排障过程发现）**：preset_save 工具把 slug 直接传给 `GetSite`（只认 uuid 且要求成员策略），模型传 slug/名称必失败；且合并解析查询 `id = $3::uuid` 在传非 uuid 值时整条 SQL 报错。修复：两处工具统一 cast 安全三态解析（uuid/slug/name，同组织同工作区内，无越权面）+ 错误详情回显实参供模型自愈。

补测同轮发现的测试侧问题（非产品缺陷）：attachments.object_key 全局唯一——补测脚本固定键撞历史行；工具策略需显式 `allow_low_write:true` 才对模型可见 LowWrite 工具。
