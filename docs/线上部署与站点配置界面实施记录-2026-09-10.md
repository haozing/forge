## 一、线上部署（含历史遗留修复）

本次把本地积累的未上线改动全部部署，并修复了部署过程中暴露的三个真实缺陷。

### 部署步骤（可复用）

1. 本地打包含新代码：`tar -czf deploy.tar.gz --exclude={.tools,.gotoolchain,tmp_deploy,tmp_qa,.git,*.tar.gz,.env*,*.exe} .`
2. 上传 `/home/ubuntu/`，在 `/home/ubuntu/agentchunzhi` 解压覆盖。
3. `docker compose up -d --build migrate`（迁移）→ `docker compose up -d --build --force-recreate api worker`。
   - **注意**：Go 编译约 5–10 分钟，SSH 直连会超时，需 `nohup ... &` 后台跑并轮询日志。

### 修复一：迁移基线 checksum 不匹配（阻断部署）

`migration.Run` 对已应用迁移做 sha256 校验，发现线上库 `0013`–`0028` 的记录与仓库文件**全部不一致**（线上是历史某次部署用早期文件内容写入的；仓库侧文件后来被修订过），迁移器以“applied baseline is immutable”拒绝执行，api 因 schema contract 检查失败进入崩溃循环。

处理：以**当前仓库文件为准**刷新 `system.schema_migrations.checksum`（表结构早已应用、语义未变），另对仅在仓库新增但线上未执行的 `0028_site_model_views.sql` 手工补跑 DDL。执行前已 `pg_dump` 备份该表到服务器 `/tmp/schema_migrations_backup_0910.sql`。

### 修复二（真 bug，新增）：内置资源模型在线上完全不可读

`model.resource_models.workspace_id` 对四个内置模型（builtin_document/note/faq/shot）为 **NULL**（组织级共享），但 `Get`/`GetVersion` 把空 workspace 一概判为 `ErrNotFound`，导致：

- `GET /api/resource-models/{id}`、`GET /api/resource-model-versions/{id}` → 404
- 站点「字段展示」白名单校验（`ValidateModelViewReferences`）对内置模型报 unknown model
- 管理员无法通过 API 改内置模型的通道策略

修复（`internal/resourcemodel/service.go`、`internal/site/modelview.go`）：

| 位置 | 修复 |
| --- | --- |
| `Get` 查询 | `rm.workspace_id::text` → `COALESCE(rm.workspace_id::text, '')`（NULL 扫描进非指针 string 会失败） |
| `Get` 过滤 | `rm.workspace_id = NULLIF($3,'')::uuid OR $4`（避免空串转 uuid 报错） |
| `Get`/`GetVersion` 授权 | workspace 为空时按**组织级**放行（成员可读）；`PatchVersion` 要求组织管理员 |
| `ValidateModelViewReferences` | 白名单校验纳入 `rm.workspace_id IS NULL` 的内置模型 |

回归测试：`internal/resourcemodel/builtin_visibility_test.go`（3 条，锁住 COALESCE、org 级放行、白名单纳入）。

### 修复三：`requestIDWriter` 不透传 `http.Flusher`（此前已修，本次上线）

## 二、站点「首页与导航」可视化配置（P2）

background：站点渲染早已支持 `navigation_config.items` 与 `homepage_config.sections`，但管理台无编辑入口——建站后两项配置恒为空，站点只能用最简默认形态渲染（这正是“看着简陋”的主因）。

新增 `src/features/site/components/site-home-nav-tab.tsx` + 站点详情「首页与导航」Tab：

- **站点导航**：增/删/上下移导航项（label + href），上限 30 项（与设计文档一致），空值前端拦截。
- **首页栏目**：增/删/排序栏目，类型（最新内容/精选绑定/栏目聚合）、标题、栏目聚合的 `section_slug`、条数（limit）；`column` 类型附“需在内容绑定里设置相同栏目标识”的提示。
- 保存为整体替换 PATCH（`navigation_config` + `homepage_config`），走既有 If-Match 乐观锁；发布版本后对外生效。
- 单测 `site-home-nav-tab.test.tsx`（3 条：回显、新增保存、空地址拦截）；mock handlers 补两项配置的 PATCH 透传。
