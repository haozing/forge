## 2. 页面与 TDK 定稿

### 2.1 总目录页 `/external-links`（首发）

- **Title**：`External Links Directory for SEO | Free Backlink Submission`（58 字符）
- **Meta Description**：`Curated external links directory for indie developers & SaaS sites. Submit your site for a free quality backlink, plus best practices for external linking SEO.`
- **H1**：`External Links Directory & SEO Guide`
- **面包屑**：Home > External Links

### 2.2 分类子页（P2，各分类 ≥10 条后拆分）模板

- 路径：`/external-links/seo-tools`、`/external-links/monetization`、`/external-links/website-building`、`/external-links/content-creation`、`/external-links/operations`
- **Title 模板**：`{Category} External Links | Curated Directory for Developers`
- **H1 模板**：`{Category} External Links Directory`
- **canonical**：各子页自指；总目录页的分组锚点不改
- **Community Picks 位**：每分类页固定一个「Community Picks」区块，展示提交者自己的站点（奖励外链）；同分类按 URL 去重取最新，与主目录收录区视觉区分（标签区分），链接属性受全站 nofollow 风险开关管控
- 关键词唯一化：每子页只承载本分类长尾词，与总目录页大词互不冲突

### 2.3 规则说明页 `/external-links/submission-guidelines`

- **Title**：`External Link Submission Guidelines | Free Backlink Rules`
- **Meta Description**：`Complete guidelines for submitting your site to our external links directory. Review criteria, approval process and free backlink rules.`
- **H1**：`External Link Submission Guidelines`

## 3. 总目录页内容结构（定稿）

自上而下：

1. **H1 + 引言段（150-200 词）**：植入 external links / external links for seo / backlink / submit your site；声明人工审核机制（质量信任信号）。
2. **H2 External Links by Category**：5 个 H3 分类分组（只渲染有记录的分组），每条 = 站点品牌名锚文本 + ≤160 字符原创描述 + 标签；每分组底部「View all in {category}」（P2 拆分后指向子页，拆分前锚点）。
3. **H2 Submit Your Site for a Free External Link**：引导文案（approved sites receive a quality dofollow backlink from qidu.site）+ 极简表单（Site Name / Site URL / Category / Short Description / Contact Email）+ 蜜罐字段 + 「Submission Guidelines」链接。
   - **双钩子**（推荐别人也奖励自己）：表单增加可选组「Your Website」（Your Site Name / Your Site URL）——推荐别人的工具，你自己的站点也获得一条收录位；提交者站点按同分类进分类页 Community Picks 位。
4. **H2 External Linking SEO Best Practices**：4 个 H3（What Are External Links? / How Do External Links Help SEO? / Internal vs External Links / Tips for Building Quality External Links），每节 60-100 词。
5. **H2 Frequently Asked Questions**：5 个 H3 完全匹配搜索原句，答案 1-2 句。
6. **H2 Related SEO Resources**：3 篇站内 SEO 文章（复用相关推荐管线）。

内容红线：正文 ≥300 词；站点描述全部原创；锚文本品牌名为主、禁止精确匹配堆砌；关键词密度 2-3%。

## 4. 技术执行清单

| 项 | 规范 |
|---|---|
| 结构化数据 | 总目录页 `CollectionPage`+`WebSite`；分类子页 `ItemList`；FAQ 区 `FAQPage`；规则页 `WebPage` |
| 收录 | 全线 index,follow；进 sitemap.xml；上线即提交 GSC 请求编入索引 |
| 分页 | 每页 20 条；?page=N 的 canonical 指第一页 |
| 出站链接 | `target="_blank"`；初期 dofollow；**站点级 nofollow 开关**作为算法风险预案；每月巡检死链并清理 |
| 激励链接（Community Picks） | 属「以内容换链接」的激励形态，属算法敏感区：与主目录区视觉+标签区分放置；数量占比监控（建议 <30%）；站点级 nofollow 开关优先覆盖此区，遇波动先切本区 |
| 性能 | 纯文字流 + 细线边框，无重脚本；LCP < 2s |
| 内容新鲜度 | 新审核通过自动上站（系统保证）；每月人工更新一次指南段落 |
| Agent Skill UGC | 条目级可选 Agent Skill（自动提交说明）公开渲染为代码块：差异化 UGC 拉长停留、贴合开发者受众；纯文本转义渲染，无注入面 |

## 5. 内链策略

- 顶部主导航加「External Links」入口（与知识库同级）。
- 面包屑三层：Home > External Links > {Category/Submission Guidelines}。
- 知识库 SEO 相关文章正文/相关推荐反向链回 `/external-links`（权重反哺主入口）。
- 总目录页与规则页互相链接；分类分组标题链向知识库对应分类页（/c/{path}）。
