# 外部资源准备清单

最终部署只需要 API、Worker、PostgreSQL、模型接口凭证和可选的 OSS/ASR/Embedding/Reranker。系统内置 Eino Agent，不需要部署或配置 Dify、FastGPT、Redis、NATS 或独立 Agent 服务。

## 必须准备

### PostgreSQL

- 生产环境准备 `DATABASE_URL`、数据库用户和密码，API 与 Worker 必须能访问同一实例。
- 需要 `pgcrypto`、PGroonga 和 pgvector 扩展；Compose 使用 `docker/postgres-r3/Dockerfile` 自动构建镜像。
- PostgreSQL 同时保存业务数据、River、Outbox、运行状态、事件和加密 Eino checkpoint；按部署要求配置备份、恢复和保留周期。

### 模型接口（ModelEndpoint）

管理员通过 ModelEndpoint 管理 API 创建接口并完成健康检查：

- `provider_type`：`openai` 或 `openai_compatible`。
- `base_url`：必须使用 HTTPS，并通过 `AGENT_MODEL_ALLOWED_HOSTS` 主机 allowlist；禁止私网地址和任意 URL。
- `model_name`、timeout、token 上限、temperature、streaming、structured output 和 tool calling 能力。
- API Key 使用 `AGENT_MODEL_SECRET_ENCRYPTION_KEY` 应用层加密后保存，或保存部署环境的 `secret_ref`；明文只在写入请求中出现。
- 每个 AgentApplication 绑定一个 ModelEndpoint；不同 AgentApplication 可以使用不同供应商、模型和凭证，也可以共享 endpoint。

系统级环境变量：

```env
AGENT_MODEL_SECRET_ENCRYPTION_KEY=<base64 32-byte key>
AGENT_CHECKPOINT_ENCRYPTION_KEY=<different base64 32-byte key>
AGENT_MODEL_ALLOWED_HOSTS=api.openai.com,model-gateway.example.com
AGENT_MODEL_DEFAULT_TIMEOUT_SECONDS=120
AGENT_MODEL_MAX_CACHE_ENTRIES=100
AGENT_MODEL_MAX_CONCURRENT_REQUESTS=20
```

### 首次管理员

准备 `ORG_NAME`、`ADMIN_LOGIN`、`ADMIN_PASSWORD`，运行 `go run ./cmd/bootstrap`。管理员创建 ModelEndpoint、Agent 用户、AgentApplication 和 AgentAccessPolicy；成员通过 `agent.use` 选择应用。

## 可选资源

### OSS 私有存储

设置 `OSS_REGION`、`OSS_BUCKET`、`OSS_ACCESS_KEY_ID`、`OSS_ACCESS_KEY_SECRET`，可选 `OSS_ENDPOINT`、`OSS_PREFIX`、`OSS_SESSION_TOKEN`。Bucket 只授予前缀范围的 Put/Get/Delete，不开放公开读；API 授权后才提供附件下载。使用 `scripts\external-acceptance.ps1 -RequireOSS` 验收。

### 服务端 ASR

Worker 读取已授权媒体并调用 ASR，浏览器不会接触凭证。腾讯云路径需要 `ASR_PROVIDER=tencent`、区域、引擎和 `TENCENTCLOUD_SECRET_ID/KEY`；通用 HTTP 路径使用 `ASR_ENDPOINT`、`ASR_TOKEN`、`ASR_MODEL`。准备音频样本并运行 `scripts\external-acceptance.ps1 -RequireASR -ASRSampleFile .\acceptance\sample.wav`。

### Embedding / Reranker

生产检索可配置阿里 Model Studio 等兼容服务：设置 `EMBEDDING_PROTOCOL/ENDPOINT/TOKEN/MODEL/DIMENSION` 和 `RERANKER_PROTOCOL/ENDPOINT/TOKEN/MODEL_VERSION`。未配置时开发环境使用确定性 hash embedding；语义服务故障会按查询契约降级，不影响结构化和全文查询。

## 验收数据与运维

- 至少一个资源模型、一个已发布资产版本和一个 AgentAccessPolicy，用于 RAG、引用校验、ReAct Tool 和资产整理验收。
- 运行 `scripts\permission-regression.ps1`、`scripts\capacity-baseline.ps1`、`scripts\ops-check.ps1` 和 `scripts\backup-restore.ps1`。
- 配置 PostgreSQL/Worker 积压、模型连续失败、OSS/ASR 延迟和 API 5xx 告警；为 checkpoint 加密根建立轮换和恢复流程。

## 不需要准备

- 不需要 Dify、FastGPT、外部 Agent API、共享 Docker 网络或 Provider Key。
- 不需要给浏览器提供模型、OSS、ASR、Embedding 或 Reranker 的密钥。
- 不需要旧数据迁移脚本、旧接口兼容开关或 `agent.process` 独立服务。
