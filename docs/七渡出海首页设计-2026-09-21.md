## 0. 站点架构定位（先说清楚"谁是谁"）

这次规格书明确了母品牌结构，先把站点的职责边界钉死：

| 站点 | 域名/路径 | 职责 | 状态 |
|---|---|---|---|
| **七渡出海枢纽站（本方案）** | qidu.site 根路径 | 品牌门面：3 秒讲清你是谁、分流到工具/内容/社群、信任背书 | **待建** |
| 出海知识库 | qidu.site/kb/（或子域 kb.qidu.site） | 内容站：755 篇 SEO 实战文章（已上线的那套阅读站） | 已上线，头部改版二期做 |
| 工具站（渠真/合规镜/信核/AgentBlog） | 各自子域 | 产品本体 | 部分规划中 |

平台事实（已核实）：
- forge 平台一个工作区只能建一个站点（唯一索引）→ 枢纽站需要**新建一个工作区**（如 itdqa 组织下"七渡出海"）+ 建站，即可获得独立主题快照、独立配置；
- 枢纽站的"最新出海观察"要调用知识库内容，两站同组织即可实现跨站读取（需一个小的读取扩展，见 §4.5）；
- **qidu.site 主域当前未指向服务器**（解析/路由都不存在），落地前需处理域名与备案（见 §5.3，这是上线的硬前提）。

## 1. 首页九模块逐块落地设计

按你的九模块顺序，每块标注：**[MVP 第一版做]** / **[二期]**，以及在我们平台上的实现方式。

### 1.1 顶部导航栏 [MVP]
- 左：七渡出海 + 小字 qidu.site；右：知识库 / 出海观察 / 关于（+ 二期：工具矩阵下拉）。
- **MVP 简化**：工具矩阵下拉先不做（工具未上线，下拉是空的）；行动按钮（加社群/订阅）二期。
- 实现：枢纽站自己的主题 layout；不做毛玻璃/滚动收窄（一期极简，符合"轻量"原则，二期再加）。
- 另：上一次拍板的"头部内容行与正文同宽 760px 居中"在枢纽站同样适用。

### 1.2 首屏 Hero [MVP]
- 主标题"独立开发者出海工具站"+ 副标题 + 标签行（十年全栈实战 · AI驱动提效 · 慢结构长期主义）+ 双按钮（查看工具矩阵 / 出海知识库）+ 右下弱化补充行。
- 文案照你的版本；数据行"沉淀 100+ 篇实战干货"的数字**等知识库最终篇数定稿后填**（当前可写"持续更新中"）。
- 实现：home 模板的 Hero 区，文案先写死在主题里（MVP 不做后台可编辑）；浅米背景 + 左对齐 + 极淡底纹。

### 1.3 核心能力标签区（4 卡片）[MVP]
- 渠道核验 / 合规护航 / 实战工具 / AI 提效，细线边框无阴影 + 线性小图标。
- 实现：主题写死（内容稳定，不需要后台可编辑）。图标用内联 SVG 线性图标（无外部依赖，符合 CSP）。

### 1.4 产品矩阵区 [MVP 结构 + 占位]
- 四张卡：渠真 / 合规镜 / 信核 / AgentBlog，统一"产品名+一句话价值+按钮"。
- **关键取舍**：渠真/合规镜/信核未上线 → 按你的规格**置灰标"开发中"占位**，AgentBlog 有实物可点亮；按钮"了解详情"的跳转目标未定的先 `href="#"` + 置灰。
- 实现：主题写死卡片结构，后续新增工具直接在主题里加卡（频次低，可接受）。

### 1.5 内容与知识库区 [MVP 手动 / 二期自动]
- 左：出海知识库入口卡（10+ 分类 · 500+ 篇 · 持续更新 + 进入按钮）；右：最新出海观察 3 篇。
- **MVP**：最新 3 篇先手动写死链接（指向知识库站的文章 URL），换文章=改主题快照（几分钟）；
- **二期自动**：枢纽站读取同组织知识库站的最新发布列表（需一个跨站"最新 N 篇"读取扩展，~80 行）——这是唯一需要新平台能力的地方。
- 知识库入口按钮跳知识库站首页。

### 1.6 实战案例区 [二期]（数据敏感，放二期）
- 三案例（水晶DIY+TikTok / AI博客矩阵 / 跨越小店）。你强调小数字更可信，认同；但**数字属于你的对外口径**，建议想清楚再上（上线后会被截图传播）。
- 每案例跳站内深度复盘文章——复盘文章需要新写（知识库里有素材可整理），二期做。

### 1.7 关于七渡（人设区）[MVP 简版]
- 文案照你的版本（平实口吻很对）。头像和"关注公众号/加社群"按钮二期；MVP 只放文字段。
- 头像素材需要你提供。

### 1.8 行动召唤 CTA [二期]
- 依赖社群/公众号的承接物（二维码/链接），一期没有可跳的目标；二期与案例区一起上。

### 1.9 页脚 [MVP]
- 中间链接：知识库 / 出海观察 / 关于（工具矩阵二期加）；右侧 GitHub/X/公众号/邮箱 → **需要你提供各链接目标**，MVP 先放已有项。
- 底部版权行：© 2026 七渡出海 · qidu.site · 慢结构，长期主义。

## 2. 视觉方案

- **枢纽站独立配色**（每站独立主题快照，互不影响知识库站的红基调）：主色墨蓝 `#1e3a5f`（比 #2563eb 更沉）、行动色暖橙 `#ea8a3a` 仅按钮/高亮、底米白 `#faf9f7`、正文深灰 `#2d2d2d`；
- 字体：系统无衬线栈（不引外部字体，保加载速度与 CSP）；代码感用等宽字体点缀（qidu.site 小字、标签行）；
- 排版：标题克制、行高 1.7、内容列宽沿用 760px 阅读宽；
- 装饰：仅首屏极淡底纹（CSS 渐变纹理，零图片请求）。

## 3. 平台实现方案

1. **建站**：itdqa 组织下新建工作区"七渡出海" → 建站点（slug `qidu`）→ 获得独立主题与配置；
2. **主题**：新写一套 `qidu-landing` 主题（layout + home 营销页 + 其余槽位极简复用默认），写好后走主题快照发布；知识库站主题不受影响；
3. **域名（硬前提，需要你决策/操作）**：
   - 现状：qidu.site 未指向服务器；forgeapi.qidu.site 证书也未签（等你加 TXT）；
   - 方案：qidu.site A 记录指向 101.35.49.253 + nginx 增 qidu.site vhost（`/` → 枢纽站、`/sites/itd-site-b095af/` 或 `/kb/` → 知识库站）+ DNS-01 证书（和 forgeapi 同一次 certbot 可一起签）；
   - **注意**：主域经腾讯网络访问会触发与 forgeapi 相同的未备案拦截（80 端口 webblock）——**qidu.site 做 ICP 备案是根解**，备案前国内访客可能仍被拦；
4. **最新文章联动**：MVP 手动；二期加跨站读取扩展。

## 4. 分期落地（对齐你的三阶段）

| 阶段 | 内容 | 平台工作量 |
|---|---|---|
| **一期 MVP** | 建工作区+站点+qidu-landing 主题：导航/Hero/能力卡/产品矩阵(含置灰)/知识库入口卡(手动最新3篇)/关于简版/页脚；头部 760px 居中 | 主题开发 1 天 + 建站配置半天 |
| **二期** | 案例区+CTA（等你提供数据口径与承接物）、跨站最新文章自动化、工具卡点亮与子域跳转 | 读取扩展半天 + 内容填充 |
| **三期** | 毛玻璃导航、订阅/社群转化、统计 | 按需 |
| **附带** | 知识库站首页改版（教学路径版，即上一份设计文档）作为二期内容项 | 半天 |
