## 1. 总体设计（阶段5）

**目标链路**：

```
AssetVersion(current_published_version_id)
  <- SiteContentBinding(site_id, asset_id, 展示配置)   # 绑定资产，不固定版本
  <- PublicSite(slug, 配置) 渲染（后端出 JSON 投影，React 渲染）
```

**D1 零正文复制**：站点域不存文章正文；读取时经绑定解析资产 published 指针。站点编辑=资产编辑+发布（§7.4）。

**D2 站点内容读取走统一查询服务**：列表/标签页/站内搜索经 `query.Service`（`ChannelPublicSite`）；绑定仅提供展示元数据，服务层 merge；默认仅展示已绑定内容，首页 section 可显式 `auto_discover:true` 走纯查询。匿名主体经 A2 迁移后可走完整审计流程。

**D3 安全投影（后端职责边界）**：后端 DTO 白名单投影（不含 workspace/成员/审计/草稿/置信度内部值/未授权字段），列表摘要做安全截断（剥 markdown 标记+长度上限）；**正文 markdown 原文下发，HTML 渲染与净化（DOMPurify/rehype-sanitize + CSP）归 React 端**。后端保留 goldmark 白名单渲染包 `internal/site/render.go` 仅用于摘要与 SEO 预渲染预留（默认关闭）。

**D4 缓存与发布失效**：详情 ETag=sha256(site.revision + asset.revision + version_id + display_config)；列表/首页 ETag=sha256(site.revision + 结果指纹)。发布/归档/可见性变化天然即时生效（实时解析指针+查询过滤）。公开只读端点 `Cache-Control: public, max-age=60, stale-while-revalidate=300`；管理/预览 `no-store`。

**D5' 分档可见（修订）**：`default_content_scope ∈ {public, organization, workspace}`（站点配置=该站点可暴露的可见性**上限**）。访客身份分档：
- 匿名 → public 带；
- 有效成员会话（同组织）→ 上限内含 organization 带；
- 该工作区成员会话 → 上限内含 workspace 带。
编译器 `ForPublicSite(site, visitor)` 按档产出 `AllowedVisibilities`；权限判定复用既有 membership 查询。未达档位的内容在列表/搜索/详情中一律 404/零命中（不泄露存在性）。

## 2. 数据模型（基线改写）

### 2.1 0010_site.sql

```sql
ALTER TABLE site.public_sites
    ADD COLUMN domain text UNIQUE CHECK (domain ~ '^[a-z0-9.-]+$'),   -- 仅存储校验；路由按 slug（决策 §8.3）
    ADD COLUMN homepage_config jsonb NOT NULL DEFAULT '{}'::jsonb,
    ADD COLUMN navigation_config jsonb NOT NULL DEFAULT '{}'::jsonb,
    ADD COLUMN template text NOT NULL DEFAULT 'blog' CHECK (template IN ('blog','pro')),
    ADD COLUMN default_content_scope text NOT NULL DEFAULT 'public'
        CHECK (default_content_scope IN ('public','organization','workspace'));
-- slug 规则：^[a-z0-9][a-z0-9-]{1,62}[a-z0-9]$（服务层校验）

ALTER TABLE site.site_content_bindings
    ADD COLUMN display_path text NOT NULL CHECK (display_path ~ '^[a-z0-9][a-z0-9/-]{0,120}[a-z0-9]$'),
    ADD COLUMN content_type text NOT NULL DEFAULT 'article' CHECK (content_type IN ('article','featured','about')),
    ADD COLUMN section_slug text NOT NULL DEFAULT '',
    ADD COLUMN sort_order integer NOT NULL DEFAULT 0,
    ADD COLUMN on_homepage boolean NOT NULL DEFAULT false,
    ADD COLUMN on_navigation boolean NOT NULL DEFAULT false,
    ADD COLUMN display_published_at timestamptz,
    ADD CONSTRAINT site_bindings_path_uq UNIQUE (site_id, display_path);
```

索引：`(site_id, content_type, section_slug, sort_order)`、`(site_id, on_homepage)`。

### 2.2 匿名查询与限流（A2/B5，0009/0002 改写）

```sql
-- 0009：匿名公开站点主体
ALTER TABLE retrieval.query_executions ALTER COLUMN subject_id DROP NOT NULL;
ALTER TABLE retrieval.search_sessions   ALTER COLUMN subject_id DROP NOT NULL;
-- subject_kind 现为长度 CHECK（1..30），无需改约束；应用层新增 'public_site'。
-- 0002：公开站点 IP 限流桶
ALTER TABLE security.auth_rate_limits DROP CONSTRAINT auth_rate_limits_bucket_type_check;
ALTER TABLE security.auth_rate_limits ADD CONSTRAINT auth_rate_limits_bucket_type_check
    CHECK (bucket_type IN ('login_email','login_ip','password_reset_email','password_reset_ip','invitation_ip','public_site_ip'));
```

`query.Service` 审计写入与 session 持久化对 `subject_kind='public_site'` 时 subject_id 置 NULL（列可空后成立）；匿名搜索的 session（分页 cursor）同样以可空 subject 落库，TTL 不变。

### 2.3 事件

`site.site_changed`、`site.binding_changed`（outbox+审计）；worker 消费 `asset.published` 镜像 `display_published_at`（best-effort；读取时 `COALESCE(binding.display_published_at, asset.published_at)` 兜底，双源语义固定）。

## 3. 服务与查询

### 3.1 `internal/site`：SiteService
- 站点 CRUD（workspace 归属、`site.manage`/`site.read` 权限、slug/domain 校验、revision+If-Match）；**status='disabled' 时公开面全部 404**（含站点信息端点）。
- 绑定 CRUD：仅可绑定 `publication_status='published'` 且可见性 ≤ 站点 `default_content_scope` 且模型 `channels.public_site.enabled` 的资产（写入校验一次；后续归档/降可见由读取层兜底为 404/零命中）。
- `Preview`：成员身份，返回与公开面同构的 JSON 快照（首页+列表+详情样例），`no-store`——React 预览页直接复用公开面组件。

### 3.2 `ForPublicSite` 编译器（internal/query）
入参 (site, visitor)：模型集=站点 workspace 下 `channels.public_site.enabled`（模型当前发布版本 policy）且 `rm.status='active'`；`AllowedVisibilities` 按 D5' 分档；空集 fail-closed（503 `site_content_unavailable`）。

### 3.3 详情路径（A3 修正）
`GET /posts/{displayPath...}`：binding(site, display_path) → asset → `current_published_version_id` 直读版本主数据 → 复用 `internal/query/final_authorizer.go` 的校验谓词（public 带+published+通道开启）——该谓词提取为可复用函数；不经过 Execute 四模式（查询服务无详情模式），满足 §9.2"返回前再次校验"。

### 3.4 泄露防护三层
①绑定写入校验；②ForPublicSite 分档过滤（published 强过滤复用）；③DTO 投影白名单（`PublicSiteContent`：id/slug/title/summary/markdown 原文/按 field_schema 的 fields/标签 summaries/content_kind/updated_at/published_at——不含 workspace_id、成员、审计、草稿、建议、置信度）。

## 8. 决策点（默认值已采用，改动需拍板）

1. **分档可见的会话识别**：公开面接受可选成员会话 cookie（同 API 会话）——是否允许未来扩展"站点访客独立身份"（本阶段不做）。
2. **auto_discover**：默认关（仅绑定内容）；整库博客场景开启。
3. **domain 路由**：本阶段仅 slug；domain 存储校验留部署层（反代注入 Host）。
4. **display_published_at**：事件镜像+读取 COALESCE 兜底（双源语义固定）。
5. **SEO 服务端渲染**：默认关（React 渲染）；goldmark 白名单包预留，开启属 React 联调期决策。

> 2026-09-02 决策记录：P6-3 的 suggest_tags 工具不再实施——建议列表面（SuggestionReviewService.List）为 member-only，Agent 侧暴露会引入越权读取面；Agent 感知标签建议经由 prepare 建议流与用户确认闭环即可。本文件相关表述为过程记录。
