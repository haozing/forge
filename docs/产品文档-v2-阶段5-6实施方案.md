## 1. 总体设计（阶段5）

**目标链路（完成标准原文落地）**：

```
AssetVersion(current_published_version_id)
  <- SiteContentBinding(site_id, asset_id, 展示配置)   # 绑定资产，不固定版本
  <- PublicSite(slug, 配置) 渲染
```

**D1 零正文复制**：站点域不存任何文章正文；`site` 包只管理「站点配置 + 绑定展示元数据」。读取时经绑定解析资产 published 指针取版本。站点编辑=资产编辑+发布（§7.4）。

**D2 站点读取全部走统一查询服务**：列表/标签页/站内搜索/详情经 `query.Service` 的 `ChannelPublicSite`（§7.3 硬性要求）；绑定仅提供展示元数据（路径/排序/栏目），在服务层与查询结果 merge。详情复用查询服务详情能力（同源最终授权），不另写直读 SQL。

**D3 渲染安全**：goldmark 限制集渲染——禁 raw HTML/危险协议、链接协议白名单（http/https/mailto）、附件仅输出受控公开下载链接（经授权校验的 presigned）；结构化字段按模型 field_schema 类型白名单投影（内部字段、审计、成员身份零暴露）；渲染发生在 API 层产出**渲染安全 DTO**（markdown→安全 HTML 由消费端渲染？决策：后端返回原文 markdown+字段投影，HTML 渲染归阶段6 前端；后端仅对**搜索摘要/列表 excerpt** 做安全截断。理由：§7.3 安全渲染约束落在展示层，前端渲染配合 CSP；后端保证不泄露未授权内容）。
> 若产品要求服务端渲染（如 SEO 预渲染），预留 `render.md` 内部包（goldmark 白名单），阶段6 前端联调时决定启用。

**D4 缓存与发布失效**：
- 详情页 ETag = sha256(site.revision + asset.revision + version_id + display_config)；列表/首页 ETag = sha256(site.revision + 结果指纹（资产id:版本id 列表）)。支持 304。
- 发布/归档/可见性变化**天然即时生效**：每次读取实时解析 published 指针与查询服务过滤（§7.2 "新版本发布后站点自动读取新版本"）。无失效窗口。
- `Cache-Control: public, max-age=60, stale-while-revalidate=300`（公开面只读端点）；管理/预览面 `no-store`。

**D5 可见性语义**：公开站点访客无身份 → 站点只能展示 `visibility='public'` 且 `channels.public_site.enabled=true` 的模型下已发布资产。`default_content_scope` 列按文档保留但 CHECK 仅允许 `'public'`（写明决策：organization/workspace 内容永不进公开 URL；内部预览走带身份的预览端点）。

## 2. 数据模型（0010_site.sql 基线改写）

```sql
ALTER TABLE site.public_sites
    ADD COLUMN domain text UNIQUE CHECK (domain ~ '^[a-z0-9.-]+$'),  -- 可选绑定域名；本阶段仅存储校验，路由按 slug
    ADD COLUMN homepage_config jsonb NOT NULL DEFAULT '{}'::jsonb,   -- {hero_asset_id?, sections:[{type:latest|featured|column, column?, limit}]}
    ADD COLUMN navigation_config jsonb NOT NULL DEFAULT '{}'::jsonb, -- {sections:[{slug,title,kind:blog|column|page}]}
    ADD COLUMN template text NOT NULL DEFAULT 'blog' CHECK (template IN ('blog','pro')),
    ADD COLUMN default_content_scope text NOT NULL DEFAULT 'public' CHECK (default_content_scope = 'public');

ALTER TABLE site.site_content_bindings
    ADD COLUMN display_path text NOT NULL,          -- 站内路径段（如 posts/hello-world），UNIQUE(site_id, display_path)
    ADD COLUMN content_type text NOT NULL DEFAULT 'article'
        CHECK (content_type IN ('article','featured','about')),
    ADD COLUMN section_slug text NOT NULL DEFAULT '',   -- 归属栏目（navigation_config.sections.slug）
    ADD COLUMN sort_order integer NOT NULL DEFAULT 0,
    ADD COLUMN on_homepage boolean NOT NULL DEFAULT false,
    ADD COLUMN on_navigation boolean NOT NULL DEFAULT false,
    ADD COLUMN display_published_at timestamptz,     -- 上架时间：绑定创建/资产发布事件镜像资产 published_at，仅排序展示
    ADD CONSTRAINT site_bindings_path_uq UNIQUE (site_id, display_path);
```

索引：bindings `(site_id, content_type, section_slug, sort_order)`；`(site_id, on_homepage)`。事件：`site.content_binding_changed`（创建/更新/删除）、站点变更审计。发布事件（`asset.published`）由 worker 镜像 `display_published_at`（best-effort，读取时兜底取资产 published_at）。

## 3. 服务与查询（新 `internal/site`）

- `SiteService`：站点 CRUD（workspace 归属、`site.manage` 权限、slug/domain 校验、revision 推进）；绑定 CRUD（仅可绑定 `publication_status='published'` 且 public 可见且模型 public_site 通道开启的资产——绑定校验一次+读取时查询服务兜底）；`Preview`（成员身份 + 站点配置快照渲染，no-store）。
- `ForPublicSite` 编译器（internal/query/scope_compiler.go）：入参 site → workspace → 模型集（`channels.public_site.enabled` 于模型当前发布版本 policy，`rm.status='active'`）→ `AllowedVisibilities=['public']` → seal。空集 fail-closed（503 `site_content_unavailable`）。
- 公开读取组装（`internal/site/render.go`）：
  - 列表/搜索/标签页：`query.Service.Execute(ChannelPublicSite)`（fulltext/structured/tags_any/all/none 复用）→ 结果与 bindings merge（补 display_path/sort/section），未绑定的命中**默认包含**（站点=查询视图而非白名单？决策：**默认仅展示已绑定资产**，`include_unbound=false` 为契约默认；首页 sections 可显式开 `auto_discover:true` 走纯查询。理由：完成标准"站点只能绑定已发布版本"暗示绑定即上架；auto_discover 供"整库博客"场景）。
  - 详情：binding(asset) → `query` 详情通道（FinalAuthorize 复检 public+published+通道）→ 版本内容投影。
- 泄露防护三层：①绑定写入校验；②ChannelPublicSite 查询过滤（public 可见+通道+published 强过滤复用）；③DTO 投影白名单（PublicSiteContent：id/title/summary/markdown/按 schema 的 fields/标签 summaries/updated_at/版本发布时间——不含 workspace_id/成员/审计/草稿字段/confidence 内部值）。

## 8. 风险与决策点

1. **服务端渲染 vs 前端渲染**（D3）：默认前端渲染+后端白名单投影；SEO 需要时启用预留的 goldmark 渲染包。
2. **绑定白名单 vs 自动发现**（§3）：默认仅绑定内容；`auto_discover` 供整库博客。若产品坚持纯视图，可去掉绑定展示元数据——不建议（路径/排序/栏目无处安放）。
3. **domain 路由**：本阶段按 slug；domain 解析（反代注入 Host/X-Site-Host）留部署层，后端仅存校验。
4. **display_published_at 镜像**依赖事件 worker；读取时兜底资产 published_at，双保险。
