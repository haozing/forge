# 知识库 AI 问答（/ask）设计文档——公开站访客 Chat（2026-09-21）

> 状态：**设计稿，待拍板后实施**。
> 需求（用户拍板）：公开站要有**类 chat 窗口**的 AI 问答；**登录才能用**；**访客有额度**。

## 1. 产品形态

```
七渡出海 /ask 页面（需登录）：

┌────────────────────────────────────────────┐
│  AI 问答 · 基于本站 755 篇实战文章            │
├────────────────────────────────────────────┤
│  [AI] 根据「饱和建站」的思路，新站冷启动应该…    │
│  [你] 新站多久能有第一批流量？                 │
│  [AI] 通常 2-8 周不等，取决于…               │
│        来源：新站流量波动诊断 · 饱和建站 ↗     │
│  ┌──────────────────────────┐ [发送]        │
│  │ 输入你的问题…              │  剩余额度 14/20│
└────────────────────────────────────────────┘
```

- **入口**：头部导航加"AI 问答"；未登录访问 → 页面渲染"登录后可与 AI 对话"引导卡（链接 /login），登录后回到 /ask；
- **Chat 形态**：消息列表 + 底部输入框 + 发送；回答**流式输出**（SSE，打字机效果）；每条 AI 回答下方标注**来源文章链接**（点击进详情，流量留站内）；
- **会话范围**：MVP 为页面内会话（刷新清空，服务端保留最近 N 轮上下文供追问）；跨设备历史二期；
- **额度**：每成员每日 **20 问**（可配置），页面常显"剩余额度 14/20"；用尽后输入框禁用 + 提示"今日额度已用完，明日恢复"。

## 2. 架构与复用（几乎全是现成件）

| 件 | 复用方式 |
|---|---|
| **RAGRuntime.StreamChat**（agentruntime/rag.go） | **直接复用**：检索→引用校验→LLM→流式事件，控制台对话同款引擎。需新配一个"站点范围检索器"（见下） |
| 站点范围检索 | 新实现 `PublicSiteRetriever`：走 PublicReader 的站点收录查询（fulltext，三道闸+排除+收录范围天然生效），只检索**该站点已收录公开内容**——与 /c/、搜索同边界，无越权面 |
| 成员会话 | 复用现有成员会话（公开站评论已用成员 Cookie 闸门），/ask 校验成员登录态 |
| 公开限流 | 复用公开 IP 预算（PublicReader.allow 同款），另加成员日额度 |
| LLM | 站点配置绑定模型端点（默认用组织现有 P8-deepseek），RAGRuntime 已管端点版本/用量统计 |
| Chat 岛 JS | 复制搜索岛（search island）模式：`/static/chat.js` 静态脚本（CSP `script-src 'self'` 允许），SSE 渐进渲染 |

## 3. 数据模型（新迁移 0046）

```sql
site.chat_sessions (id, site_id, member_id, created_at)          -- 会话（轻）
site.chat_messages (id, session_id, site_id, member_id,
    role, content, citations jsonb, tokens int, created_at)      -- 消息与引用
```

- **额度**=当日（created_at 今日）role='user' 消息数，按 (site_id, member_id) 计数——不建额度表，查询时 count；
- 数据保留策略：消息保留 30 天后可清理（后续可加清理任务，MVP 不做）。

## 4. 端点设计

| 端点 | 说明 |
|---|---|
| `GET /sites/{slug}/ask` | Chat 页面（SSR 壳 + chat 岛）；未登录渲染引导卡（200，含登录 CTA） |
| `POST /api/public/sites/{slug}/chat` | 发消息：`{session_id?, message}` → **SSE 流式**返回（delta + 最终 citations/usage）；未登录 401；额度尽 429（附恢复时间）；新会话返回 session_id |
| `GET /api/public/sites/{slug}/chat/quota` | 剩余额度（页面加载时取） |

行为细节：
- 检索**仅限该站点已收录公开内容**（Retriever 强制带 site_id scope）；
- 回答必须**引用站内文章**（grounded）；无检索命中时如实回答"知识库暂无相关内容"并推荐分类；
- 额度校验在 LLM 调用**之前**；审计记 chat.ask（member 维度）；
- 首条系统提示注入**站点简报**（复用 injectSiteBrief 语义），回答贴合站点定位。

## 5. 安全与成本边界

| 风险 | 防护 |
|---|---|
| 免登录滥用 | 不提供免登录通道：必须成员会话 |
| token 成本失控 | 成员日额度 20 问 + 单问 token 上限 + 公开 IP 预算复用 |
| 提示注入 | 站点内容作为不可信上下文（RAG 模板围栏，与控制台对话同款） |
| 越权 | 检索器硬绑 site_id，只出公开收录内容（不可配置放宽） |
