## 2. 组织级通知列表（N5）

- 新路由 `GET /api/notifications`：按 recipient 聚合组织内所有工作区的通知，`limit/unread_only/cursor`（十进制 stream_id），复用统一的 `notificationColumns` + `presentNotification`。
- 前端顶部栏的全局未读数不再需要按工作区聚合请求。

## 3. 审核结果邮件（N8）

- 模板 `publication_decision`（`internal/notification/templates.go`），payload：`action / asset_title / decision_comment / link`；链接指向 `PUBLIC_APP_BASE_URL + /workspaces/{ws}/knowledge`。
- `review.Service` 新增 `Cipher / KeyVersion / BaseURL`（组装根 `cmd/api/main.go` 注入，与邀请邮件同一套加密投递队列）；`decide()` 事务内 `enqueueDecisionEmailTx`：批准/驳回且决策人≠提交人时给提交人发信，信件入队失败按既有约定回滚整个决策事务。
- 三字段全部可选：不接邮件配置时决策仅站内通知，行为不回退。

## 4. 成员面通用限流

- `rateLimitMiddleware` 新增 `/api/*`（**不含 `/api/public/*`**，公开面有自己的匿名预算）分支：按会话 cookie 摘要分桶（无 cookie 回退来源地址），默认 240 req/min，`RATE_LIMIT_MEMBER_PER_MIN` 可调；429 带 `Retry-After: 30`。
- `.env.example` 已补键。

## 5. ConfirmVersion 并发幂等（0027 迁移）

- `db/migrations/0027_confirm_version_idempotency.sql`：部分唯一索引 `(organization_id, parent_version_id) WHERE parent_version_id IS NOT NULL AND confirmation_status='human_confirmed'`，并发双确认在库侧被封死。
- 迁移内置存量双胞胎折叠：优先保留被 `current_working_version_id` 引用的行，仅删除无引用、无子版本、非发布指针的多余行；若仍有被引用的冲突行则索引创建显式失败交人工裁决。
- 本地库实测：重复候选 0，应用成功。

## 6. Agent ReAct 读工具补 data_scope 可见性过滤（授权越界修复）

- `tool_factory.go` 新增 `agentVisibilityBand`：按 `content.agent_access_policies.data_scope`（workspace 级行优先于组织级行）解析可见性带，查不到 fail-closed 为 public-only。

## 7. 站点评论分页 + summary 端点

- 新路由 `GET /api/workspaces/{workspaceId}/sites/{siteId}/summary`（site.read）：`bindings_count + pending_comments_count`，概览页免拉全量列表。
