# 首页改版设计文档——入门教学导向首页（2026-09-21）

> 状态：**设计稿，待拍板，未实施**。
> 需求来源（用户原话）：①菜单导航要和内容一样宽，容器居中；②把现在的首页放到"文章"页；③首页放用户步骤教学文章和我们的简介等信息。

---

## 1. 背景与目标

当前首页 = 站名 + 分类区块 + 最新文章大列表（100 篇）+ 标签云。问题：

- 首页与"文章"页（/posts/）内容几乎重复，首页没有承担"导览"职责；
- 新访客不知道从哪读起——755 篇平铺，缺一条"从零到上线"的阅读路径；
- 站点定位（是什么、给谁看、怎么用）没有在首页讲清楚。

**改版目标**：首页从"文章列表"转为"**站点门面 + 新手学习路径 + 导览**"；全量文章列表保留在"文章"页（/posts/，已带分页，天然承接）。

## 2. 头部容器修正（样式项，随本次一并实施）

现状：头部条通栏，内容顶到屏幕两边。目标：**头部内容行与正文同宽（760px 阅读宽）并居中**，背景条仍通栏——视觉上头部与正文对齐，像文档页眉。

```
|========================= 通栏背景 ==========================|
|  [站名]        首页 文章 标签              [搜索]          |  ← 内容 760px 居中
|=========================================================|
|        站名 h1（正文区，居左）                             |
```

实现：header 内加一层与 `.site-main` 同参数的容器（`max-width: var(--reading); margin: 0 auto`），三段式 grid 不变。纯 CSS + 主题快照发布，不动后端。

## 3. 新首页结构设计

```
┌────────────────────────────────────────────┐
│ 头部（单行居中，见 §2）                       │
├────────────────────────────────────────────┤
│ ① 站名 h1 + 一句话简介（已有）                 │
│    [开始学习 ↓]  [浏览全部文章 → /posts/]      │
├────────────────────────────────────────────┤
│ ② 新手入门 · 学习路径（本次核心新增）           │
│    按顺序编号的 6 篇步骤教学，卡片带序号与         │
│    一句话说明，"按此路径读" 即完成入门           │
├────────────────────────────────────────────┤
│ ③ 按分类浏览（现有分类 chips 区块，保留）        │
├────────────────────────────────────────────┤
│ ④ 最新文章（8 篇 + "查看全部 →" 到 /posts/）   │
├────────────────────────────────────────────┤
│ ⑤ 关于本站（2-3 句简介 + 搜索/标签入口说明）     │
├────────────────────────────────────────────┤
│ ⑥ 标签云（现有，保留在尾部）                    │
└────────────────────────────────────────────┘
```

要点：
- **"文章"页承接原首页**：/posts/ 已是全量列表+分页，首页大列表移除后它就是唯一的全量入口，首页 ④ 只放最新 8 篇 + 明显的"查看全部文章"链接；
- **学习路径是"有序"的**：与分类（主题聚合）不同，路径强调阅读顺序，卡片带 01/02/… 序号与一句话"这步做什么"。

### 4.2 数据承载方案（对比后二选一）

| 方案 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| **A. 站点配置驱动（推荐）** | pages_config 新增 `path` 区块类型：`{type:"path", title, asset_ids:[有序]}`，读取端按序取文章；管理后台可在站点配置里改顺序/换文章 | 内容运营与代码解耦；顺序可控；后续换文章不改代码 | 需要一次后端小扩展（解析+读取+VM，~100 行） |
| B. 主题写死 | 把 6 篇 slug 写进 home.tmpl | 零后端改动 | 换文章要改主题；不通用 |

推荐 **A**：区块化首页本就是站点系统的设计方向（pages_config v2），`path` 类型补上"有序精选"这个缺口，以后任何站都能用。

### 4.3 简介与文案

- 一句话简介：复用站点 description 字段（已有，首页顶部已显示）；
- "关于本站"块：新增站点配置复用 brief 字段或直接写死在主题（2-3 句：内容范围 + 更新频率 + 怎么用本站）——**待拍板**（§7）。

## 6. 验收标准

1. 首页出现"新手入门 · 学习路径"有序区块（6 篇、带序号、顺序正确）；
2. 首页大列表消失，"最新文章"仅 8 篇且有"查看全部"链接到 /posts/；
3. /posts/ 全量列表+分页功能不变；
4. 头部内容行与正文同宽居中；移动端布局不破；
5. 首页仍是单 h1、JSON-LD/OG 正常、冷渲染 <300ms。
