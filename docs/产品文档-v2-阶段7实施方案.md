## 1. 验收环境与预检（.env 真实配置）

### 1.1 .env 键名盘点（2026-08-30 实测，仅键名）

**已有且可用**：`APP_ENV`、`DEEPSEEK_API_KEY`、`EMBEDDING_ENDPOINT/MODEL/PROTOCOL/TOKEN/DIMENSION`、`RERANKER_ENDPOINT/MODEL_VERSION/PROTOCOL/TOKEN`、`OSS_ACCESS_KEY_ID/SECRET/BUCKET/ENDPOINT/REGION`、`TENCENTCLOUD_SECRET_ID/KEY`、`ASR_*`、`AGENT_MODEL_ALLOWED_HOSTS`、`AGENT_MODEL_SECRET_ENCRYPTION_KEY`、`AGENT_CHECKPOINT_ENCRYPTION_KEY`、`SEARCH_CURSOR_SECRET`、`POSTGRES_PASSWORD`。

**生产模式 fail-fast 必填、当前缺失**（`config.Validate` 在 `APP_ENV=production` 下逐项拒绝启动）：

| 缺失键 | 要求 | 用途 |
| --- | --- | --- |
| `MEMBER_ALLOWED_ORIGINS` | 非空、不含 `*`，绝对 origin | 成员面 CORS |
| `PUBLIC_APP_BASE_URL` | https 绝对 URL | 邀请/重置邮件链接 |
| `MAILER_PROVIDER` | 必须 `smtp` | 生产禁用 capture |
| `SMTP_HOST` / `MAIL_FROM` | 非空 | 真实邮件投递 |
| `RATE_LIMIT_HMAC_KEY` | ≥32 字节 | 限流桶 HMAC |
| `EMAIL_DELIVERY_KEYS` + `EMAIL_DELIVERY_CURRENT_KEY_VERSION` | `VERSION:<base64 32字节>` | 邮件负载数据加密 |
| `QUERY_HASH_SECRET` | ≥32 字节且 ≠ SEARCH_CURSOR_SECRET | 查询审计哈希 |
| `RETRIEVAL_EMBEDDING_MANIFEST_KEY` / `MODEL_VERSION` | 与其余 manifest 键成套 | 检索语义清单 |
| `RETRIEVAL_EMBEDDING_DIMENSIONS` | 必须 1024 | 维度校验 |

**键名不匹配（必须先解决，否则真实 embedding/reranker 根本不会被读到）**：代码读取 `RETRIEVAL_EMBEDDING_*` 与 `RETRIEVAL_RERANKER_*`（internal/config/config.go:105-116），而 `.env` 现存键名为 `EMBEDDING_*` / `RERANKER_*`（无前缀）。处置（二选一，验收前完成）：
- A（推荐）：把 `.env` 四个 embedding 键、四个 reranker 键改名为带 `RETRIEVAL_` 前缀；
- B：在 docker-compose environment 段做别名映射（不改 .env）。
改名后用 `GET /readyz` 验证 `semantic_available=true`（当前 readyz 返回 ready 但语义清单为空——键没被读到）。

**其余预检**：
1. `AGENT_MODEL_ALLOWED_HOSTS` 必须覆盖真实端点 host（DeepSeek `api.deepseek.com`、embedding/reranker 真实 host；值不回显，验收人自查）。
2. 生产模式**禁止** `AGENT_MODEL_ALLOW_PRIVATE_EGRESS`（Validate 拒绝启动）——mock TLS 栈（`.env.test` + `tmp_qa/mock_tls.py` + `docker-compose.override.yml` 挂 mock CA）在本阶段**全部停用**；`docker-compose.override.yml` 建议暂时移出目录（保留副本），保证真实 TLS 链路纯净。
3. `.env` 补齐后仍连本机 postgres 容器（compose 内 `postgres:5432`）——"真实"指外部云依赖真实，数据库仍是本地容器重建库（上线检查单 §8 另含生产库项）。
4. `APP_ENV=production` 影响面：cookie 变 `__Host-agent_session`（Secure+HttpOnly+SameSite=Lax；curl cookie jar 在 localhost 可正常携带）；配置 fail-fast 全量生效；登录/邀请/公开站点限流全开。
